## 🚀 Getting Started

<details>
<summary><b>Click to expand setup steps</b> 👇</summary>

<br>

**1. Clone the repository**
```bash
git clone https://github.com/shreyaverma0407/portfolio.git
```

**2. Move into the project folder**
```bash
cd portfolio
```

**3. Open it locally**
```bash
open index.html
```

That's it — no build step, no dependencies. 🎉
